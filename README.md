# 100-days-of-code-version-C-programming-
Daily code logs and practice exercises tracking my journey learning programming fundamentals and building projects.

## Copilot Prompt Guide for Practice

Use these ready-to-copy prompts while learning and sharing progress in this repository.

### 1) Learning Syntax & Basic Concepts

- **Explain code in plain terms**
  - "Explain what this function does step-by-step in simple terms. Break down what each variable and loop is doing: [paste code here]"
- **Syntax help**
  - "Show me how to declare a 2D array in [C++ / Java / Python] with comments explaining the syntax."
- **Translating logic to code**
  - "I want to write logic that checks if a given number is prime. Don't write the full code yet—give me the pseudocode and logic step-by-step first."

### 2) Debugging & Error Resolution

- **Fixing compilation or runtime errors**
  - "I am getting the following error: [paste error message]. Explain why this error happens in my code and how I can fix it: [paste code]"
- **Finding edge case bugs**
  - "Here is my code for [describe task, e.g., reversing an array]. What edge cases (like empty arrays, single elements, or negative numbers) will cause this code to fail?"

### 3) Code Quality & Git Prep

- **Adding clear comments for GitHub**
  - "Add clear, beginner-friendly inline comments to this code so anyone reading my GitHub repository can understand what each part does: [paste code]"
- **Writing a Git commit message**
  - "Write a short, professional Git commit message in imperative mood for these changes: [describe changes, e.g., Added binary search implementation for sorted arrays]"
